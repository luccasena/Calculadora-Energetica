# Calculadora Energetica

Projeto desenvolvido por uma iniciativa extensionista do Unipê chamada  **Percursor Analisys** que simula o consumo de energia eletrica de aparelhos residenciais.

A aplicacao permite adicionar aparelhos, informar quantidade, potencia e horas de uso por dia. Com esses dados, ela calcula uma estimativa de consumo diario e mensal em kWh, mostra quais aparelhos mais consomem energia e apresenta um custo aproximado com base em uma tarifa de referencia.

## Funcionalidades

- Cadastro de aparelhos pre-configurados.
- Cadastro de aparelhos personalizados.
- Edicao e remocao dos aparelhos adicionados.
- Calculo do consumo diario e mensal.
- Ranking dos aparelhos com maior consumo.
- Estimativa simples do custo mensal de energia.

## Tecnologias

- Python
- Streamlit
- Pandas
- Plotly

1. Crie e ative um ambiente virtual.
2. Instale as dependencias:

```bash
pip install -r requirements.txt
```

3. Execute a aplicacao:

```bash
streamlit run app_streamlit.py
```
